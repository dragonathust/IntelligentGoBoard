# 智能围棋棋盘
本项目利用低成本的微型磁芯来构造棋子检测传感器。本电子棋盘主要由多条水平和垂直导线以及导线交叉处的磁芯构成的传感器阵列构成。带有磁体的棋子靠近磁芯时，磁场的作用会导致行线和列线间的耦合关系发生变化，通过合适的电路检测到这种变化。通过轮流驱动行线和检测列线，就可以扫描并识别到整个棋盘上所有交叉处有无棋子。
## 硬件
棋盘作为一个USB外设，使用USB虚拟串口与对弈设备通信。
MCU采用STM32F103C6T6，监听对弈设备发来的指令，扫描传感器阵列和触摸按键并返回数据给对弈设备，同时接收数据来扫描LED阵列，驱动彩色LED状态灯，驱动扬声器。
整个棋盘正常工作功耗(LED不亮的条件下)在5V，30mA左右。
对弈设备可以是运行linux的PC，ARM/MIPS CPU板，或Android手机(TODO)。
## 软件
五子棋引擎使用了Carbon/Pela AI算法，内存需求在4MB量级。
围棋引擎使用了GnuGo，内存需求在64MB量级,要在十秒左右落子需要CortexA53及以上性能的CPU。
